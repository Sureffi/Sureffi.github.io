Overview_

CienceTerminal is a real-time ingestion platform that handles high-volume social signal data via WebSockets and REST APIs for Solana tokens. It scans Twitter streams, extracts contract addresses, verifies them on-chain, and delivers tiered alerts to users before price moves.

The platform surfaces attention signals — tracking how many influencers mention a token, the velocity of mentions, and the quality of the accounts pushing them. This gives traders a measurable edge in the memecoin market where attention precedes price action.

Built from scratch as a production SaaS with secure authentication, role-based access controls, and tiered subscription plans. The React frontend was built with a focus on responsiveness, intuitive UX, and real-time interactive visualization of social signals.

Managed full CI/CD pipelines and containerized deployments for automated, reproducible releases across multiple environments.

Features_

Real-time Ingestion

High-volume data pipeline processing social signals via WebSockets and REST APIs. Contract addresses extracted and verified on-chain in real-time.

Attention Scoring

Tracks mention velocity, influencer quality, and trending signals across Twitter. Surfaces tokens gaining attention before price discovery.

Tiered Alert System

SignalR websocket push notifications with tier-based access. Pro users receive alerts with lower latency and higher signal fidelity.

Microservices Backend

AWS-native architecture using ECS containers, SNS/SQS message queues, and event-driven processing for scalable, fault-tolerant operation.

Production React Frontend

Interactive real-time data visualization, responsive layout, and intuitive UX built for traders.

Auth & Access Control

Secure authentication with role-based access, subscription management, and tiered feature gating across the platform.

Architecture_

System Design

The backend is built on .NET microservices deployed to AWS ECS. Social data flows through SNS/SQS message queues for decoupled, asynchronous processing. Each service handles a specific domain — ingestion, verification, scoring, and alerting — communicating through events.

The frontend connects via SignalR websockets for real-time push updates. Supabase handles user data and auth state. The entire stack is containerized with Docker and deployed through automated CI/CD pipelines.
