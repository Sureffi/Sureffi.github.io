Overview_

Created the first Lua-based mod menu for FiveM, the multiplayer modification framework for GTA V. At the time, no Lua-based mod menus existed for FiveM — existing solutions used different approaches. This required reverse-engineering the client/server communication protocols and understanding the runtime scripting environment from scratch.

The mod menu provided real-time modular scripting capabilities with runtime control over game entities, player state, and server interactions.

The project required deep understanding of event-driven systems — FiveM uses a networked event model where client and server communicate through typed events. Understanding this model was essential for building reliable, responsive modifications.

Gained experience in low-level debugging, performance optimization within tight frame budgets, and building modular systems that could be extended without destabilizing the host application.

02 //

Features_

First of Its Kind

The first Lua-based mod menu for FiveM. Required reverse-engineering undocumented client/server protocols to build from scratch.

Reverse Engineering

Analyzed FiveM client/server communication, networked event model, and runtime scripting environment without existing documentation.

Modular Architecture

Extensible plugin system allowing new modules to be added without modifying core code. Runtime loading and unloading of features.

Real-time Control

Live manipulation of game entities, player state, and server interactions with immediate visual feedback in the game world.

Performance Optimized

Built within tight frame budget constraints. Lua execution optimized to avoid frame drops during complex operations.

Event-driven Design

Built on FiveM's networked event model with proper client-server synchronization and state management across the multiplayer environment.
