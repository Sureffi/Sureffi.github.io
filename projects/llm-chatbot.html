Overview_

A Telegram chatbot platform where users interact with AI-powered celebrity personality clones. Each personality was crafted through prompt engineering and fine-tuning to capture distinct communication styles, mannerisms, and knowledge domains — creating a realistic conversational experience.

Users could switch between personalities dynamically mid-conversation, with the system maintaining context and adapting its responses to match the selected persona's voice and expertise.

Built on a multi-tenant architecture supporting credit-based usage and subscription management. Each user has their own conversation history, credit balance, and personality preferences tracked independently.

Deployed on Azure with cloud GPU optimization to manage inference costs. Monitored scaling, latency, and resource usage to balance response quality with operational economics.

02 //

Features_

Celebrity Personas

Multiple AI personalities cloned from celebrity communication styles. Each with distinct voice, knowledge, and conversational patterns crafted through prompt engineering.

Dynamic Switching

Users can switch between personalities mid-conversation. Context is maintained while the AI adapts to the new persona's style and expertise.

Credit-Based Billing

Multi-tenant billing system with credit tracking, subscription tiers, and usage monitoring. Each user has independent credit balances and conversation limits.

Real-time Chat Pipelines

Low-latency message processing through Telegram's API with streaming responses and fast turn-around times for natural conversation flow.

GPU Cost Optimization

Azure cloud GPU deployment with monitoring for scaling, latency, and resource utilization. Balanced response quality against operational costs.

Microservices Architecture

Separate services for model inference, user management, billing, and conversation routing — all containerized with Docker.

03 //

Architecture_

System Design

Messages from Telegram are routed to a personality-aware inference service that selects the appropriate system prompt and conversation context. The billing service deducts credits per interaction and enforces subscription limits.

Model inference runs on Azure GPU instances with auto-scaling based on queue depth. User management handles registration, credit purchases, and subscription state. All services communicate through Docker-networked microservices with health monitoring and graceful degradation.
